# Candidate Generation Policy (候補生成方針)

1着確率予測結果から、舟券購入の対象となる組み合わせ（3連単等）を生成するための数学的アプローチ。

## 1. 近似アルゴリズム: Plackett-Luce モデル
競艇は独立した試行ではないが、1着確率 $p_i$ が既知の場合、2着・3着の確率は以下の条件付き確率で近似する。
$P(i-j-k) = P(i) \times \frac{P(j)}{1-P(i)} \times \frac{P(k)}{1-P(i)-P(j)}$

## 2. 生成範囲の制限
計算コストとノイズ削減のため、以下の制限を設ける。
- **1着候補**: モデル予測確率上位 N 名（デフォルト 3 名）
- **組み合わせ数**: 1レースあたり最大 M 通り（デフォルト 20 通り）

## 3. バリデーション
- 生成された各組み合わせの確率の総和が 1.0 を超えないこと（数学的整合性）。
- 非現実的な極低確率（例：0.01%以下）の組み合わせは生成時にカットする。
