# Missing Strategy for Features (特徴量欠損値戦略)

モデルがエラーを起こさず、かつバイアスを最小限にするための補完戦略。

| 特徴量タイプ | 補完方法 | 理由 |
| :--- | :--- | :--- |
| **選手能力** (勝率等) | 全体平均 (または級別平均) | 未知の選手でも平均的な実力と仮定 |
| **ST** (スタート) | 全体平均 | 極端に遅い/早いと仮定するのは危険 |
| **機力** (2連率等) | 40.0% (標準的な値) | 新モーター等でデータがない場合の初期値 |
| **展示** (タイム) | 同レース内他艇の平均 | 水面状況が全艇に共通するため |

## Missing Flags
- 特徴量が補完された場合、`{col_name}_is_missing` というバイナリフラグを立てる。
- これにより、モデルが「この数値は推測値である」という情報を学習に利用できるようにする。
