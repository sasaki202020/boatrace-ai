# Threshold Tuning Plan: 閾値最適化計画

「的中率」と「回収率」のバランスを取るための、EV（期待値）閾値の調整手順です。

## 1. チューニングの目的
- **硬い運用**: 的中率を重視。EV 1.2 以上をターゲット。
- **攻める運用**: 回収率（一撃）を重視。EV 0.9 でも高オッズなら狙う。

## 2. 調整箇所
- `config/strategy_config.json` 内の：
    - `min_ev_threshold`: 購入を推奨する最小期待値。
    - `min_win_proba`: 最低限必要な1着確率（例: 0.35 = 35%）。

## 3. 実験サイクル
1. 現在の閾値でレポートを出す。
2. 閾値を `+0.1` ずつ変化させた時の、的中レースの「取り逃し」と、不的中レースの「回避」をカウントする。
3. **F1スコア** （的中率と再現率の調和）が最大になるポイントを探る。

## 4. 禁止事項
- **過学習（オーバーフィッティング）**: 直近数レースの結果だけに合わせるな。通算 100 レース以上の結果を母集団とせよ。
