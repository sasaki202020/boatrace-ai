# BoatRace-AI-MVP: 実データ適合開始ガイド

設計フェーズ（Gate 1-6）が完了しました。これより **「実データ適合」** フェーズに移行します。
ここからの勝負は「すごいAI」ではなく、**「実ファイル（Raw）とプログラム（Alias/Role）の整合性」** です。

## 🚀 最短の着手手順

### 1. 実データの配置
ダウンロードした公式データ（LZH解凍後のTXTまたはCSV）を以下のディレクトリに配置します。
- **配置先**: `data/raw/official/`

### 2. 列名エイリアスの監査
実データの列名がプログラムで正しく認識されているか確認します。
```cmd
py src/ingest/inspect_raw_columns.py
```
- **出力確認**: `docs/raw_column_audit.md` を開き、`UNKNOWN`（未知）な列がないか確認します。

### 3. エイリアスの修正（必要な場合）
未知の列がある場合、またはマッピングが間違っている場合は設定を更新します。
- **修正ファイル**: `config/column_aliases.json`
- **ヒント**: `py src/ingest/suggest_alias_candidates.py` を実行するとマッピング候補が表示されます。

### 4. フルパイプライン実行
整合性が取れたら、一気にレポート生成まで走らせます。
```cmd
py master_run.py
```
または、作成した [run_master.bat](file:///c:/Users/goo10/競艇/boatrace-ai-mvp/run_master.bat) をダブルクリックして実行し、ログを確認してください。

## 🔍 優先的に疑うべき箇所（トラブルシューティング）
モデルの精度を疑う前に、まず以下の3点を確認してください。
1. **Raw**: 読み込んでいるファイルは正しいか？（不完全なデータではないか）
2. **Alias**: `national_win_rate` などの重要列が正しくマッピングされているか？
3. **Role**: 目的変数（`win_label`）に未来の情報（着順など）が混入していないか？
