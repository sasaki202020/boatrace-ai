# Evaluation Metrics (評価指標の定義)

モデルの性能を「当てるだけでなく、不確実性を正しく評価できているか」の視点で測定する。

## 1. 主要指標 (Core Metrics)
- **Log Loss**: モデルが出力した確率の「自信」と「正確さ」を測定。0に近いほど良い。期待値計算の基礎となる確率の信頼度を示す。
- **AUC-ROC**: 1着とそれ以外をランク付けする能力。

## 2. ギャンブル特有指標
- **Top-1 Accuracy**: 最も1着確率が高いと予測した艇が実際に1着だった割合。
- **Calibration Error**: 予測確率が 20% と言ったとき、実際に 20% 程度の頻度で当たっているか。
- **ROI (Simulated)**: 期待値が 1.0 を超えた買い目のみに賭けた場合の仮想的な回収率。

## 3. 採点基準
| 指標 | 優秀 | 合格 | 警告 |
| :--- | :--- | :--- | :--- |
| Log Loss | < 0.40 | < 0.45 | > 0.50 |
| Top-1 Acc | > 45% | > 40% | < 35% |
