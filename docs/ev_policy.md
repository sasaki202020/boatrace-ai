# EV Policy (期待値評価方針)

算出された確率と市場オッズを比較し、「賭ける価値」を定量化する。

## 1. 基本式
$Expected Value (EV) = 予測確率 \times オッズ$

## 2. 投資判断基準
| EV 値 | 判断 | アクション |
| :--- | :--- | :--- |
| **EV >= 1.2** | 特注 | 積極的な購入検討。 |
| **1.0 <= EV < 1.2** | 買い | 資金管理に基づき購入。 |
| **EV < 1.0** | 見送り | 控除率を考慮すると長期的にはマイナス。 |

## 3. オッズの扱い
- 確定オッズではなく、締切直前の「直前オッズ」を使用する。
- 期待値が極端に高い（例：EV > 5.0）場合は、データ異常や特異なバイアスを疑い、警告を出す。

## 4. 暫定運用条件（2026-03-15 反映）
- `min_win_proba = 0.25` を BUY 判定の最低条件として適用する。
- `risk_flag = True` は BUY 除外（強制 SKIP）とする。
- 本条件は BUY 件数と実運用安定性の暫定バランス確認を目的とした運用設定。
