# Calibration Policy (更正方針)

モデルが出力する生確率を、実際の勝率の頻度（実測値）と一致させるためのポリシー。

## 1. 必要性
ロジスティック回帰や一部のGBDTは、確率が過小または過大に振れる傾向がある。期待値 $E = P \times O$ を計算する際、$P$ が歪んでいると期待値も誤る。

## 2. 手法
- **Isotonic Regression / Platt Scaling**: 現在の MVP では複雑さを避けるため実装を保留するが、Log Loss が改善しない場合の次の一手とする。

## 3. レース内補正 (Normalization)
- 1つのレースにおける 6 艇の「1着確率の合計」は必ず 1.0 (100%) になる必要がある。
- モデルの出力を $p_i$ としたとき、$\hat{p}_i = \frac{p_i}{\sum_{j=1}^6 p_j}$ として正規化を行う。
