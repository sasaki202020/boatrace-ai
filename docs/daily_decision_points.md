# Daily Decision Points: 日次意思決定基準

システムが出したレポートに対し、最終的に「買う・買わない」を判断する際のセーフティネットです。

## 🟢 GO (投資対象)
以下の条件をすべて満たす場合のみ、レポートの推奨に従う。
- **Status PASS**: `validation_summary.json` が正常である。
- **EV > Threshold**: 期待値が設定した閾値（デフォルト1.1）を明確に超えている。
- **Consistency**: 特徴量の重要度（Feature Importance）上位の項目が、直感的な有力選手（A1級、インコース等）と矛盾していない。

## 🟡 HOLD (慎重/少額)
以下の場合、投資額を減らすか、見送りを検討する。
- **悪天候**: 風速 7m/s 以上の荒天時（モデルの平時前提が崩れる可能性がある）。
- **データ不足**: 選手の今節成績や展示タイムが取得できていない（欠損値補完に頼りすぎるリスク）。
- **オッズ急変**: 直前でオッズが大幅に下がり、期待値が 1.0 を割り込んだ場合。

## 🔴 STOP (即時中止)
以下の場合、そのレース（またはその日）の運用を中止する。
- **Schema Mismatch**: 列名のエイリアス監査で `UNKNOWN` が発生した。
- **Outlier**: 1着確率が 1.0 を超える、または負になるなどの計算異常。
- **Environment**: ターミナルログに Python のエラーやリソース不足が記録されている。

---
**格言**: 最良の投資判断は「買わない」こと。迷ったら STOP せよ。
