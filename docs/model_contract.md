# Model Contract (モデル構築契約)

## 1. 入出力の透明性
- 入力特徴量は `feature_registry.json` に記載されたもののみを使用する。
- 出力ファイルは `config/model_config.json` で定義されたパスに必ず保存する。
- `model_bundle.json` には、モデルのバージョン、学習日時、および特徴量リストを含める。

## 2. 実運用への配慮
- `win_proba_raw` (モデルが出力した生確率) と `win_proba_norm` (レース内 6 艇の合計が 1.0 になるよう補正した確率) を区別して出力する。
- 推論時に 1 艇でも欠落しているレースは、原則として推論をスキップするか、警告を出す。

## 3. 再現性の確保
- `random_state` を固定し、同一データセットから同一モデルが生成されることを保証する。
- モデルファイル（joblib等）と共に、学習に使用した `model_config.json` のスナップショットを保存する。
