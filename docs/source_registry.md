# Source Registry

本プロジェクトがサポートする公式データ源の定義。

## 1. 過去レースデータ
- **Source**: BOAT RACE 公式サイト -> 競走成績ダウンロード
- **File Pattern**: `KSE*.TXT` (LZH解凍後)
- **Status**: 実装予定 (Gate 2)

## 2. 番組表
- **Source**: BOAT RACE 公式サイト -> 番組表ダウンロード
- **File Pattern**: `KBN*.TXT`
- **Status**: 実装予定 (Gate 2)

## 3. 期別成績
- **Source**: BOAT RACE 公式サイト -> ダウンロード・他 -> レーサー期別成績
- **File Pattern**: `fan*.txt`
- **Status**: 後回し (Gate 2初期はCSVマニュアル配置)
