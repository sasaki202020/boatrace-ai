# Missing Value Policy (欠損値補完方針)

データが欠落している場合、勝手な推測をせず、以下のルールに従って処理する。

| 項目カテゴリ | 推奨アクション | 補足 |
| :--- | :--- | :--- |
| **選手成績** (勝率等) | 全国平均値で置換 | 級別ごとの平均値が望ましい |
| **モーター/ボート係数** | 0.0 または 40.0 (平均付近) | 初おろし等でデータがない場合 |
| **展示タイム** | そのレースの他艇平均値 | または欠損フラグを立てて別途処理 |
| **気象情報** | 近傍レースまたは場平均 | 欠損が多い場合はレースごとスキップ |
| **級別 (Class)** | 'B2' (最低ランク) 扱い | 安全側の倒した処理 |

## 例外
- `race_id` や `lane` が欠損している場合は補完せず、当該レコードを破棄する。
