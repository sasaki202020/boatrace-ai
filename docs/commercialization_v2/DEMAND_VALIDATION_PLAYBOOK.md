# Demand Validation Playbook

仮説: 自分で候補を決めたいが、全raceを調べる時間がなく、候補絞り込みと確率表示を求めるユーザー。

14日目標は15人との会話。過去の具体行動、代替手段、調査時間、有料情報経験、信用に必要な証拠、確率だけの価値、希望料金、実際のbeta登録を記録する。

- STRONG_SIGNAL: 5人以上に具体課題、3人以上が実登録、2人以上が有料代替利用、価格提示後も意思が残る
- WEAK_SIGNAL: 興味のみで登録・行動なし、課題が曖昧、無料意向だけ
- NO_SIGNAL: 課題あり3人未満、既存代替で十分、確率表示に価値なし

支払いは受け付けない。
