# Source Rights Registration

source rightsはprediction timingと別gateである。証拠原本、SHA-256、発行組織、許可用途、モデル入力、数値保存、raw保存、derived prediction公開、商用利用、有効期間を登録する。

不明・null・期限切れは`UNVERIFIED`または`EXPIRED`としてfail-closedにする。source rights未確認でもsynthetic fixtureテストは可能だが、payment、有料beta、実予測公開、raw公開、commercial claim、API販売は禁止する。
