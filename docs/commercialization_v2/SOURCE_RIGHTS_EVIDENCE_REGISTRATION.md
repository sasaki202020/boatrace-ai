# Source Rights Evidence Registration

Use only after a written response is received.

1. Preserve the original `.eml`, PDF or issued document without rewriting it as the sole evidence.
2. Calculate lowercase SHA-256 and record the original relative path.
3. Record received time, issuer organization, department, representative/reference number and validity period.
4. Transcribe each permission field without expanding its meaning.
5. Independently verify the file hash and original format.
6. Keep `status=UNVERIFIED` until every required field has an explicit answer and a human approves registration.
7. Never store personal contact details in public reports.

Registration must not automatically set commercial use, publication or payment flags. Expiry, revocation, missing evidence or hash mismatch returns the status to fail-closed.
