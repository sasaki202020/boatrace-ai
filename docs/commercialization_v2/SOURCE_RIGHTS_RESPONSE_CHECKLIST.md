# Source Rights Response Checklist

- [ ] Written response received from an authorized organization.
- [ ] Original `.eml`, PDF or equivalent source retained.
- [ ] Issuer organization and department identified.
- [ ] Representative or reference number identified.
- [ ] Covered source/file/screen is exact.
- [ ] Acquisition method is explicit.
- [ ] Model-input use is explicit.
- [ ] Numeric storage is explicit.
- [ ] Raw-file storage is explicit.
- [ ] Derived prediction storage is explicit.
- [ ] Derived prediction publication is explicit.
- [ ] Free beta use is explicit.
- [ ] Commercial use is explicit.
- [ ] API and third-party provision are explicit.
- [ ] Retention and deletion conditions are explicit.
- [ ] Request limits are explicit.
- [ ] Valid-from, valid-until and revocation conditions are explicit.
- [ ] Attribution requirements are explicit.

Unchecked, null or ambiguous items are fail-closed. The unsent request itself never satisfies this checklist.
