# User Interview Script

誘導せず、直近の具体行動を聞く。

1. 直近でrace検討へ時間を使った場面を教えてください。
2. 何を見てraceを除外しましたか。
3. 現在使う代替手段と、1日あたりの調査時間はどの程度ですか。
4. 有料情報を買った経験と、継続・解約した理由は何ですか。
5. 予測を信用するために、どの証拠が必要ですか。
6. 確率表示だけでも価値がありますか。候補提示まで必要ですか。
7. 月額と都度払いではどちらが自然ですか。実際に払った近いサービスはありますか。
8. 無料betaの案内を希望する場合だけ、本人の意思で連絡先を残してもらいます。
