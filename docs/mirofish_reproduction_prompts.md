# MiroFish 再現専用：黄金の4段階プロンプト集

Antigravity で MiroFish の構造を安全に解析・再構築するためのプロンプトセットです。

## 🛡️ Step 1: 構造解析 (調査のみ)
リポジトリの全体像を把握し、実装の前提を整理します。

```text
あなたはこのプロジェクトの開発エージェントです。
目的は「MiroFish の構造を研究し、同等機能の予測システムを安全に再構築すること」です。
対象は GitHub リポジトリの構造を理解し、最小変更で段階的に再現することです。

【重要方針】
- 一度に全部作らない
- 必ず調査 → 設計 → 実装 → テスト の順
- 推測で実装しない
- 変更は最小単位
- 外部APIや依存追加は必ず確認
- 回答は日本語で簡潔に

【最初のタスク】
GitHub の MiroFish リポジトリを確認して
・システム構成
・使用言語
・依存ライブラリ
・予測ロジック
・実行方法
を整理してください。まだコードは変更しないでください。
```

## 📐 Step 2: 機能分解 (最小単位)
いきなり全部作らず、3つの要素に分解して優先順位を決めます。

```text
このプロジェクトを再現するために必要な最小機能を3つに分解してください。
※「データ取得」「特徴量生成」「予測/判断」の観点で整理してください。
```

## 📝 Step 3: 限定的実装計画
分解した機能のうち、最初の1つ（例：データ取得）に絞った計画を立てます。

```text
最初の機能（データ取得ボット）だけ実装する計画を出してください。
既存の MiroFish のコードから、どの部分を抽出・参考にするか明確にしてください。
```

## 🛠️ Step 4: 安全な最小実装
計画に基づき、動作確認が可能な最小限のコードのみを生成させます。

```text
安全な最小コードを生成してください。
依存ライブラリの追加が必要な場合は、事前に確認してください。
```
