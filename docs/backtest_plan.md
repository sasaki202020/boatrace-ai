# Backtest Plan: 過去データによる検証計画

モデルが「未知のデータ」に対してどれだけ通用するかを、過去の時系列を用いて検証します。

## 1. 検証期間の設定
- **学習**: 直近1年前〜1ヶ月前まで。
- **検証 (Hold-out)**: 直近1ヶ月分。
- **理由**: 競艇は季節性やエンジンの更新時期があるため、近すぎず遠すぎないデータが必要。

## 2. 検証フロー
1. `config/model_config.json` の `test_size_days` を 30 に設定。
2. `py src/models/train_win_model.py` を実行。
3. `data/model_outputs/test_metrics.json` を確認。
4. 特徴量重要度（Feature Importance）を確認し、ノイズになっている列を特定。

## 3. シミュレーション項目
- **全買い**: すべての「BUY」判定。
- **期待値ソート**: EV 1.5 以上の厳選投資。
- **本命絞り**: 1着確率 60% 以上のレースのみ。

## 4. フィードバックループ
- バックテストで「大外れ」したレースの `raw` データを見直せ。
- 特徴量に「その日の風速」や「展示タイム」の重みが反映されているか点検せよ。
